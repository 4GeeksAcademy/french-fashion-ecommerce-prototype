# Collaboration contract

- **Objective:** Deliver a coherent, rubric-complete five-view static prototype through authentic three-person collaboration.
- **Mode:** `COLLABORATIVE_MODE_PILOT`, case-specific; no global Control Tower canon change.
- **Authority:** Assignment/rubric and Control Tower canonical state govern academic claims. ORCH-00 owns decisions and gates. Allowed write ownership is part of execution authority.
- **Ownership:** EXP-01 alone publishes the four creative contracts before lock and owns Home. DISC-02 owns Catalog/Product; TRAN-03 owns Cart/Checkout. INTEG-04 owns later cross-page SEO/Schema and conformance after handoff. No simultaneous ownership of the same HTML file.
- **Branch policy:** Use the prepared feature branches where appropriate, sync with main before PR, retain contributor commits, avoid force-push and direct-main feature work. Normalization uses its own chore branch.
- **Review policy:** One reviewable PR per major part with rubric coverage, contract versions, viewport evidence, deviations and handoff. ORCH-00 checks ownership and gates before integration.
- **Attribution:** Real team members author their work. GitHub identities are pending; do not simulate them.
- **Dependencies:** ORCH-00 → EXP-01 → DISC-02 and TRAN-03 → INTEG-04. DISC/TRAN require transversal contracts APPROVED/FROZEN. INTEG requires both handoffs.
- **Handoffs:** Record owner, commit/PR, contract versions, tests, evidence, known limitations, decisions and open questions. The receiver acknowledges before modifying shared surfaces.
- **Contract mutation:** DRAFT work belongs to EXP-01. After lock, workers request ORCH-00 decision through the deviation protocol. Only an authorized publisher amends a contract with version/status and impact review.
- **Integration order:** Shared foundation (merged) → creative lock/Home golden reference → Catalog/Product and Cart/Checkout → SEO/Schema/cross-page QA → rubric baseline → bounded excellence.
- **Human gates:** Real collaborator identities/access; subjective reference/visual/copy approval when needed; any destructive or materially ambiguous decision; final submission.
- **Failure/escalation:** Stop for missing lock, ownership collision, contradictory source, unreviewed deviation, unsafe overwrite, or missing evidence. Classify PASS, REPAIRABLE, GUIDED or CAPABILITY_GAP and use the rescue protocol. Preserve attribution.
