# Visual contract

The following are normative slots. EXP-01 must record approved values, examples and responsive exceptions before DISC-02 or TRAN-03 starts. No creative token is locked by this scaffold.

| Area | Contract to lock |
| --- | --- |
| Color | palette, semantic roles, contrast and surface hierarchy: TO_LOCK_IN_EXP01 |
| Typography | families, scale, weights, line heights and hierarchy: TO_LOCK_IN_EXP01 |
| Spacing | base scale and section rhythm: TO_LOCK_IN_EXP01 |
| Containers | max widths and side gutters: TO_LOCK_IN_EXP01 |
| Grid | page and product grid behavior by viewport: TO_LOCK_IN_EXP01 |
| Border | stroke roles and contrast: TO_LOCK_IN_EXP01 |
| Radius | component radius roles: TO_LOCK_IN_EXP01 |
| Shadow | elevation roles or explicit none: TO_LOCK_IN_EXP01 |
| Images | aspect ratios, crop/focal and alt treatment: TO_LOCK_IN_EXP01 |
| Product cards | media, information order, price, action and states: TO_LOCK_IN_EXP01 |
| Buttons | primary/secondary styles, hit area and disabled states: TO_LOCK_IN_EXP01 |
| Inputs | label, hint, error and focus treatment: TO_LOCK_IN_EXP01 |
| Selects | visual parity and native behavior: TO_LOCK_IN_EXP01 |
| Forms | field grouping, validation messages and mobile layout: TO_LOCK_IN_EXP01 |
| Header/footer | shared structure and responsive menu behavior: TO_LOCK_IN_EXP01 |
| Focus | visible keyboard indicator and contrast: TO_LOCK_IN_EXP01 |
| Hover | consistent enhancement without hiding core action: TO_LOCK_IN_EXP01 |
| Motion/effects | bounded duration, reduced-motion handling or none: TO_LOCK_IN_EXP01 |
| Responsive behavior | 390x844, 768x1024, 1440x900 rules and overflow prevention: TO_LOCK_IN_EXP01 |

EXP-01 must render and accept Home as the golden reference before propagation. Later changes require versioned amendment and affected-page review.
